# DS font library (open-licence files)

Free fonts with the SIL Open Font License, served from here for any DS page: `/assets/fonts/<family>/<file>.woff2`. Each folder keeps its licence file. Use the files unchanged (no subsetting or renaming).

Apfel Grotezk, Ronzino, Mazius Display, Necto Mono (Collletttivo); Azeret Mono, JetBrains Mono, Sora, Teko (Google).

Fontshare families (Cabinet Grotesk, Panchang, Array, Amulya, Aktura, Kola, Switzer, Satoshi) are **not** stored here. Their licence (ITF FFL v2) forbids putting the files in a public repository or converting them. Load them on live pages through the Fontshare API, e.g. `<link href="https://api.fontshare.com/v2/css?f[]=cabinet-grotesk@800&display=swap" rel="stylesheet">`. The originals are in Lethabo's DS Fonts folder (Desktop/DIGITAL SWITCH/DS Fonts) for testing.
